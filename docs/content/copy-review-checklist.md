# Copy review checklist

**Control issue:** #22

Use this checklist for every page brief and copy-bearing PR.

## Source and provenance

- [ ] Every content block cites a source: canonical brief, claims register, sales deck, team bios, existing-site audit, or client-approved copy.
- [ ] Sales-deck language has been rewritten as web-native copy, not pasted wholesale.
- [ ] Raw team biography material has been edited for concise public use.
- [ ] Any missing source is recorded as an open decision rather than invented.

## Voice and positioning

- [ ] proof before claim.
- [ ] specific over generic.
- [ ] Senior, discreet, precise, human.
- [ ] Partner-led where relevant.
- [ ] The crossing/navigation/depth idea is used only where it adds meaning.

## Avoid list

Do not use these without explicit strategic approval:

- “trusted adviser to leading companies”
- “at the intersection of capital and innovation”
- “deep sector expertise” without concrete proof
- “long-term value creation”
- “we partner with exceptional founders”
- vague global finance boilerplate
- deck shorthand that reads like a pitch slide rather than a website

## Compliance gate

- [ ] Relevant `CL-*` IDs from `docs/compliance/claims-register.md` are listed.
- [ ] Gate A/B status is understood.
- [ ] No “authorised” language unless cleared by counsel/company secretary.
- [ ] Named counterparties/case studies anonymised unless consent is documented.
- [ ] Superlatives and hard factual claims are substantiated, hedged, or removed.
- [ ] Financial-promotion/investor-gating implications routed to compliance.
- [ ] Forms/privacy/analytics copy routes through GDPR/data-flow review.

## Copy freeze

Copy is frozen for implementation only when:

1. page brief exists;
2. source provenance is complete;
3. voice review passes;
4. compliance status is recorded;
5. open decisions are either resolved or the affected copy is softened/removed.
