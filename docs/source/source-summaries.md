# Source summaries

This file is deliberately compact. Use original artefacts only when a specific issue requires deeper evidence.

## Strategic brief

Lir must present as a senior, discreet, partner-led advisory firm. The site should win on proof, senior credibility, and discretion, with “the crossing” as the ownable idea. Imagery and critique loops are central to avoiding AI-template output.

## PRD

Static-first Astro, minimal attack surface, git-based content, Caddy/VPS hosting, CI quality gates, accessibility and performance requirements, password-gated pre-prod.

## Design-language spec

Dark-dominant, editorial, navigational visual system using Obsidian, Atlantic Deep, Aged Gold, Atlantic Slate, and Parchment. Newsreader + Inter. No first-generation design ships.

## Compliance review

Gate A before build copy: authorisation language, regulated-activity mapping, named-counterparty consent, claim substantiation, financial-promotion gating. Gate B before deploy: entity disclosure, GDPR, bio accuracy, endorsements/testimonials.

## Photography brief

Commissioned partner portraits and atmosphere imagery are make-or-break. No stock or AI stand-ins. Neutral placeholders only for pre-prod.
